# @nestus/config

Shared TypeScript / ESLint configuration presets for all NestJS apps and packages.

- `tsconfig.base.json` — strict, ES2022, bundler module resolution (shared packages)
- `tsconfig.nest.json` — CommonJS + decorators (NestJS apps)
- `tsconfig.next.json` — Next.js app preset
- `eslint.config.mjs` — flat ESLint preset (typescript-eslint + import order)
